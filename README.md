# Laravel Admin

A multilingual admin panel built on **Laravel 13** and the Metronic admin theme, with two developer tools on top:

- **CRUD Generator** – builds a complete translatable CRUD module (migrations, models, requests, controller, Blade views, routes, sidebar link, permissions) from a form in the admin panel.
- **Smart Seeder** – fills any module with realistic, multilingual demo data generated by Google Gemini, including real photos from Pixabay.

## Features

- **Multilingual content** – languages are managed in the panel (az / en / ru seeded, Azerbaijani default); every content module stores its texts in a `*_translations` table.
- **Roles and permissions** – [spatie/laravel-permission](https://github.com/spatie/laravel-permission) on the `admin` guard, with `{module} index|create|show|edit|delete` permissions.
- **Blog module** – the reference CRUD: DataTables listing with search and bulk delete, Quill rich text editor, image gallery with cover selection.
- **Translations panel** – edit UI texts in the browser; file translations can be imported into the database.
- **Settings, admins, roles, permissions, logs** – activity log via [spatie/laravel-activitylog](https://github.com/spatie/laravel-activitylog).
- **Login security** – optional rate limiting and reCAPTCHA, configurable by developers.
- **Image uploads** – stored on the `documents` disk with type, size and MIME validation.

## Requirements

- PHP 8.3+ with `gd`, `pdo_mysql` (or `pdo_sqlite`) and `fileinfo`
- Composer 2
- MySQL 8 / MariaDB (SQLite works for local testing)

The admin theme assets are shipped in `public/backend`, so Node.js is not required to run the panel.

## Installation

```bash
git clone https://github.com/Emrah2121/laravel-admin.git
cd laravel-admin

composer install
cp .env.example .env
php artisan key:generate
```

Set the database connection and the URL you open the site with in `.env`:

```dotenv
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_admin
DB_USERNAME=root
DB_PASSWORD=
```

> `APP_URL` must match the address in the browser – uploaded image URLs are built from it.

Then create the tables, seed the default data and link the storage:

```bash
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Open **http://127.0.0.1:8000/gload/login-admin**.

| Account | E-mail | Password | Role |
|---|---|---|---|
| Administrator | `admin@admin.com` | `password` | Admin – all permissions |
| Developer | `developer@gmail.com` | `password` | Developer – everything, plus the developer tools |

**Change these passwords before deploying anywhere public.**

## Developer tools

Both tools write files into the codebase, so they are available only to the **Developer** role and only while `APP_ENV=local` (override with `CRUD_GENERATOR_ENABLED=true|false`). In production they return 404.

### CRUD Generator

Sidebar → Developer → **CRUD Generator**

1. Enter a module name (e.g. `Product`) and choose the base columns (slug, publish date, order, status).
2. Add fields: `string`, `textarea` (plain or Quill rich text) or `image`, each translatable or not, required or optional.
3. Preview every file that will be created and the exact lines that will be added to existing files.
4. Confirm – optionally run the new migrations and `PermissionSeeder` right away.

The new module follows the Blog module's conventions and appears in the sidebar with its own permissions. Generation is atomic (rolled back on any error), never overwrites files, and the same engine is available from the command line:

```bash
php artisan crud:make --spec=product.json --dry-run
php artisan crud:make --spec=product.json --migrate --seed
```

Details: [docs/crud-generator.md](docs/crud-generator.md)

### Smart Seeder

Sidebar → Developer → **Smart Seeder**

1. Add a free [Google Gemini API key](https://aistudio.google.com) and a free [Pixabay API key](https://pixabay.com/api/docs/) in the settings card (stored encrypted).
2. Pick a module, the number of records and describe the data, e.g. *"Programming services: web, mobile, backend, DevOps"*.
3. Review the generated records (all active languages, photos with credits) and click **Run seeder**.

The result is a normal Laravel seeder in `database/seeders/Smart`, so it can also be run with:

```bash
php artisan db:seed --class="Database\Seeders\Smart\{Module}SmartSeeder{timestamp}"
```

Running a seeder twice does not create duplicates. Details: [docs/smart-seeder.md](docs/smart-seeder.md)

## Project structure

```text
app/
  Http/Controllers/Backend/   admin controllers (one per module)
  Http/Requests/Backend/      FormRequest validation
  Models/                     Eloquent models + *Translation models
  Services/                   upload, translation loader, CrudGenerator, SmartSeeder
resources/views/backend/      Blade views per module + shared includes
routes/backend.php            admin routes (prefix /gload, names backend.*)
stubs/                        templates used by the CRUD Generator and Smart Seeder
docs/                         conventions, decisions and tool documentation
```

Conventions for new code (controller → FormRequest → model → Blade, no logic in Blade) are described in [CLAUDE.md](CLAUDE.md) and [docs/crud-generator-conventions.md](docs/crud-generator-conventions.md).

## Tests

```bash
php artisan test
```

The test suite uses an in-memory SQLite database. The CRUD Generator and Smart Seeder tests write into a temporary sandbox and fake every external API, so no API key is needed.
